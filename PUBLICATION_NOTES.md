# Curation Notes

This repository is a curated public evidence set for Project Boundary.

## Publication boundary

The package is intentionally selected from a private engineering and architecture-research repository. It preserves original evidence where that evidence materially supports a public architectural claim, while excluding material that would add operational history without improving independent review.

Included material may contain:

- synthetic or lab hostnames used by the prototype;
- model or product names where they are part of the evidence;
- original run identities and timestamps needed to connect artifacts;
- original architecture-change language;
- selected executable tests.

Excluded material includes:

- the private repository history as a whole;
- complete raw logs when a selected record establishes the same claim;
- private environment reachability or configuration;
- credentials or secrets;
- unrelated operational scaffolding;
- full prompts and full model-response archives;
- the complete run and test archives;
- forensic authorship records not needed to evaluate the architecture.

## Evidence handling

Where a file is identified as a verbatim source artifact, it is published without substantive rewriting. Publication-layer README and index files provide navigation, context, evidence status, and stated limits.

The repository intentionally includes negative evidence, incomplete work, and stop-state records alongside successful demonstrations.
