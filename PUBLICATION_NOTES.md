# Publication Notes

This directory is staged for publication as a standalone public repository tentatively named:

`project-boundary-evidence`

## Publication boundary

The package is intentionally curated from a private engineering/research repository. It preserves original evidence where it materially supports a public claim and removes material that is merely operational history.

Included material may contain:

- synthetic/lab hostnames used by the prototype;
- model/product names where they are part of the evidence;
- original run identities and timestamps needed to connect artifacts;
- original architecture-change language;
- selected executable tests.

Excluded material includes:

- private repository history as a whole;
- complete raw logs when a selected terminal record establishes the same claim;
- private environment reachability/configuration;
- credentials/secrets;
- unrelated operational scaffolding;
- full prompts and full model-response archives;
- the complete run and test archives;
- forensic authorship records not needed to evaluate the architecture.

Run a secret/private-reference scan over this staged tree after all files are copied. A public-repo link should not be added to the portfolio case study until the public repository exists and the published contents have been inspected in-place.
