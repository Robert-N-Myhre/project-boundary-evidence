- [Change 39 — Envelope portfolio](architecture-change-39.md): multiple bounded authority postures can coexist, with deterministic coverage selection and no silent tie-breaking.
- [Change 41 — Human operations authority / recovery](architecture-change-41.md): recovery mutation receives its own digest-bound human authorization.
